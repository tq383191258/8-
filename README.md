这是一个面向零基础学习者的 8 周大模型学习路线，目标是帮助你从 Python / 机器学习基础，到 Transformer、微调、RAG、部署与项目实战，逐步建立对大模型的理解和工程实践能力。

## 适合人群

- 零基础学习者
- 想从人工智能/大模型入门的人
- 想做自我学习路线的开发者
- 对 LLM / RAG / 微调 / 部署感兴趣的人

## 学习建议

- 每周投入 8–15 小时为宜。
- 以“理解概念 + 代码实操 + 输出小作品”为主。
- 不要一上来就追大模型论文，先建立概念和工程实践能力。

## 学习节奏

1. Week 1：Python + 线性代数 + 机器学习基础
2. Week 2：PyTorch + 深度学习基础
3. Week 3：NLP + token + embedding
4. Week 4：Transformer 原理与实现
5. Week 5：微调与 LoRA
6. Week 6：RAG & FAISS
7. Week 7：量化与部署
8. Week 8：项目整合与输出

## 资源推荐

- Python：官方教程
- 线性代数：3Blue1Brown
- ML：Andrew Ng 课程
- PyTorch：官方教程
- NLP / Transformer：CS224N、The Illustrated Transformer
- Hugging Face：官方文档和课程

## 一句话总结

零基础学习大模型，最有效的方法不是一开始啃论文，而是先掌握基础概念、Python、PyTorch、Transformer，并通过 RAG / 微调 / 部署 这些工程实践，逐步理解大模型的原理和落地方式。
