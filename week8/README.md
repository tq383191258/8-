## 目标

- 整合前 7 周知识

## 项目建议

- 文档 RAG 问答助手
- 店铺客服助手

## 实操流程

1. 明确问题域和数据来源
2. 采集/整理文档
3. 构建索引
4. 设计 prompt
5. 训练或微调模型（可选）
6. 部署一个 demo
7. 评估输出质量
8. 编写项目说明
